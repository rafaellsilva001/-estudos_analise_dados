# 📊 Estudos de Análise de Dados com NotebookLM

Projeto desenvolvido utilizando o NotebookLM como ferramenta de aprendizagem ativa para estudos de Análise de Dados, Inteligência Artificial e Engenharia de Prompts.

---

# 📌 Contexto e Objetivos

Este projeto foi desenvolvido como parte do desafio prático da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi Análise de Dados, uma área essencial para transformar dados em informações úteis para tomada de decisões.

O objetivo deste caderno temático é:

- Aprender conceitos fundamentais de análise de dados;
- Utilizar IA generativa como apoio aos estudos;
- Organizar conteúdos técnicos em um único ambiente;
- Explorar o uso de prompts para melhorar respostas da IA;
- Criar um material de consulta e revisão;
- Desenvolver habilidades iniciais na área de dados.

---

# 🧠 Tema Escolhido

- Introdução à Análise de Dados
- Python para Dados
- SQL
- Dashboards
- KPIs
- Inteligência Artificial aplicada a Dados

# 💬 Engenharia de Prompts e Testes

## Prompt 1

### Pergunta
> Explique o que é Análise de Dados de forma simples para iniciantes.

### Resultado
A IA explicou que análise de dados é o processo de coletar, organizar e interpretar dados para gerar informações úteis.

### Aprendizado
Prompts mais específicos geram respostas mais claras e objetivas.

---

## Prompt 2

### Pergunta
> Qual a diferença entre Ciência de Dados e Análise de Dados?

### Resultado
A IA explicou que Análise de Dados possui foco em interpretação e visualização, enquanto Ciência de Dados envolve Machine Learning e modelos preditivos.

### Aprendizado
Perguntas comparativas ajudam a entender conceitos semelhantes.

---

## Prompt 3

### Pergunta
> Quais habilidades um Analista de Dados precisa ter?

### Resultado
A IA destacou Python, SQL, Power BI, estatística e comunicação.

### Aprendizado
A IA consegue estruturar conteúdos de carreira de forma organizada.

---

## Prompt 4

### Pergunta
> Explique o que é KPI com exemplos práticos.

### Resultado
A IA apresentou exemplos de métricas de vendas, crescimento e desempenho empresarial.

### Aprendizado
Solicitar exemplos práticos melhora a compreensão dos conceitos.

---

## Prompt 5

### Pergunta
> Crie um roadmap para começar na área de Análise de Dados.

A IA sugeriu estudar:
- Python

- Visualização de Dados

### Aprendizado
Roadmaps ajudam a organizar os estudos de forma mais eficiente.

# ⚠️ Troubleshooting e Aprendizados

Durante os testes foi observado que:

- Prompts vagos geravam respostas genéricas;
- Perguntas muito amplas dificultavam respostas objetivas;
- Contextualizar o nível de conhecimento melhorava os resultados;
- Solicitar exemplos práticos aumentava a qualidade das respostas;
- Dividir perguntas complexas em partes menores ajudou no aprendizado.

# 📖 Miniguia de Estudos

## 🔹 O que é Análise de Dados?

Análise de Dados é o processo de coletar, organizar, interpretar e transformar dados em informações úteis para auxiliar empresas na tomada de decisões.

Seu principal objetivo é identificar padrões, tendências e insights que ajudem a resolver problemas e melhorar resultados.

---

## 🔹 Diferença entre Ciência de Dados e Análise de Dados

### Analista de Dados
Foca em:
- interpretação de dados;
- dashboards;
- relatórios;
- métricas;
- visualização de informações.

### Cientista de Dados
Possui atuação mais ampla:
- Machine Learning;
- modelos preditivos;
- automação inteligente;
- criação de algoritmos;
- desenvolvimento de soluções baseadas em IA.

---

## 🔹 Principais Ferramentas da Área

| Ferramenta | Função |
|---|---|
| Python | Automação e análise de dados |
| Pandas | Manipulação de dados |
| SQL | Consulta em bancos de dados |
| Power BI | Criação de dashboards |
| Scikit-Learn | Machine Learning |

---

## 🔹 Principais Etapas da Análise de Dados

1. Coleta de dados;
2. Limpeza e tratamento;
3. Organização;
4. Análise;
5. Visualização;
6. Geração de insights;
7. Tomada de decisão.

---

## 🔹 Importância da IA na Análise de Dados

A Inteligência Artificial permite:
- automatizar análises;
- identificar padrões complexos;
- gerar previsões;
- melhorar decisões;
- acelerar processos analíticos.

# 📘 Glossário

## IA Generativa
Tecnologia capaz de criar conteúdos como textos, imagens e códigos utilizando Inteligência Artificial.

## Machine Learning
Área da IA onde sistemas aprendem padrões através dos dados.

## Dashboard
Painel visual utilizado para acompanhar métricas e indicadores.

## KPI
Indicador utilizado para medir desempenho e resultados.

## Prompt
Instrução enviada para a IA gerar respostas.

## Engenharia de Prompts
Técnica de criação de prompts mais claros e eficientes para melhorar resultados da IA.

## Pandas
Biblioteca Python utilizada para manipulação e análise de dados.

## SQL
Linguagem utilizada para consultar bancos de dados.
